# 后端服务 Docker Compose 部署验证

## 概述

本文档用于验证后端服务在 Docker Compose 环境下的部署和运行状态，涵盖数据库、缓存和后端 API 服务的完整部署流程。

## 环境配置

- **Docker Compose 版本**: 3.8
- **Python 版本**: 3.11
- **数据库**: PostgreSQL 15 Alpine
- **缓存**: Redis 7 Alpine

## 启动命令

```bash
cd src/backend
docker-compose up -d
```

## 服务状态验证

### 容器状态

| 容器名称 | 镜像 | 状态 | 健康检查 | 端口映射 |
|---------|------|------|---------|---------|
| mindcanvas_backend | backend-backend | 运行中 (healthy) | ✅ 通过 | 8008:8000 |
| mindcanvas_db | postgres:15-alpine | 运行中 (healthy) | ✅ 通过 | 5432:5432 |
| mindcanvas_redis | redis:7-alpine | 运行中 (healthy) | ✅ 通过 | 6379:6379 |

### 验证命令

```bash
# 检查所有容器状态
docker ps -a --filter "name=mindcanvas"

# 检查后端健康状态
curl http://localhost:8008/health
# 预期输出: {"status":"healthy","service":"MindCanvas Backend"}

# 容器内健康检查
docker exec mindcanvas_backend curl -s http://localhost:8008/health
```

```

```

## 常见问题与排查

### 后端容器重启循环

**症状**: `STATUS` 显示 `Restarting (1)`

**排查步骤**:
1. 查看日志: `docker logs mindcanvas_backend`
2. 检查数据库连接字符串格式
3. 确认 `DATABASE_URL` 使用 `postgresql+asyncpg://` 前缀

**常见原因**:
- 使用了同步驱动 (`postgresql://` 或 `postgresql+psycopg2://`)
- SQLAlchemy 异步引擎需要 asyncpg 驱动

### 数据库连接失败

**排查步骤**:
1. 确认 `mindcanvas_db` 容器已启动并健康
2. 检查数据库凭据是否正确
3. 验证网络连接: `docker exec mindcanvas_backend ping db`

### 端口不可访问

**排查步骤**:
1. 检查端口映射: `docker port mindcanvas_backend`
2. 检查本地防火墙设置
3. 尝试容器内访问: `docker exec mindcanvas_backend curl http://localhost:8008/health`

## 配置说明

### 环境变量

| 变量名 | 值 | 说明 |
|--------|-----|------|
| DATABASE_URL | `postgresql+asyncpg://mindcanvas:your_secure_password@db:5432/mindcanvas` | 异步数据库连接 |
| REDIS_URL | `redis://redis:6379/0` | Redis 连接 |
| ENCRYPTION_SECRET_KEY | Fernet 密钥 | 加密密钥 |
| LOG_LEVEL | INFO | 日志级别 |
