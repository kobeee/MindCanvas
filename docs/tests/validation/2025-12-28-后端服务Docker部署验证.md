## 问题修复记录

### 问题 1: apscheduler 依赖缺失
**症状**: `ModuleNotFoundError: No module named 'apscheduler'`
**修复**: 重新构建 Docker 镜像

### 问题 2: User 模型缺少字段
**症状**: `Unconsumed column names: refresh_token, refresh_token_expires_at`
**修复**: 在 `user.py` 中添加 refresh_token 字段

### 问题 3: LoginResponse 验证错误
**症状**: `2 validation errors for LoginResponse: refresh_token Field required`
**修复**:
1. 修改 `auth_service.py` 的 `login_with_provider` 方法
2. 添加 `await self.db.refresh(user)` 确保数据加载
3. 修改 `auth.py` 传递新字段到 LoginResponse

### 问题 4: EncryptionService 初始化错误
**症状**: `TypeError: EncryptionService.__init__() missing 1 required positional argument: 'secret_key'`
**修复**: 在 `tasks.py` 中导入 `settings` 并传递 `settings.ENCRYPTION_SECRET_KEY`

### 问题 5: TaskResponse datetime 验证错误
**症状**: `Input should be a valid datetime [type=datetime_type, input_value=None]`
**修复**: 将 `created_at` 和 `updated_at` 字段改为可选

### 问题 6: SQLAlchemy async rollback 错误
**症状**: `IllegalStateChangeError: Method 'rollback()' can't be called here`
**修复**: 在 `_update_task_status` 和 `_clear_api_key` 方法中添加 rollback 异常处理
