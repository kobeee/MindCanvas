## 概述

本文档用于验证《编辑器问题修复与生成流程优化方案 v1.0》在 iOS 端的实现效果，覆盖：

- P0：缩放 HUD 数字同步、双指捏合缩放、绘图时笔划闪烁/消失
- P1：图生图确认预览浮窗
- P2：文生图（无参考图生成资源）

## 环境准备

- **系统**：iPadOS 17+
- **工程**：`src/MindCanvas/MindCanvas.xcodeproj`
- **运行目标**：iPad 模拟器或真机（建议真机验证 PencilKit 体验）

## 启动/关闭

- **启动**：Xcode 选择 iPad 目标运行 App
- **关闭**：停止运行或退出 App

## 日志查看

- **Xcode Console**：查看运行日志与错误输出

## 测试用例

### 1) 问题1：缩放 +/- 按钮点击后百分比数字更新

- **步骤**
  - 进入任意项目 -> 原生编辑器
  - 在左下角 Zoom HUD 连续点击 `+` / `-`
  - 观察百分比文本是否随缩放同步更新
- **预期**
  - 实际画布缩放发生变化
  - HUD 百分比文本与实际缩放一致，并能在 pinch 缩放后同步更新

### 2) 问题2：双指捏合缩放支持

- **步骤**
  - 进入编辑器
  - 切换到对象模式，双指捏合缩放画布
  - 切换到绘图模式，双指捏合缩放画布
- **预期**
  - 两种模式下均可通过双指捏合缩放画布
  - 缩放范围在 50%~300% 内（受 min/max zoom 限制）

### 3) 问题3：绘画模式下笔划消失/闪烁

- **步骤**
  - 切换到绘图模式
  - 连续绘制多笔划
  - 在绘制过程中观察历史笔划是否出现“暂时消失、松手后恢复”的现象
- **预期**
  - 绘制过程中历史笔划稳定显示，不出现闪烁/短暂消失

### 4) 图生图：确认预览浮窗

- **步骤**
  - 打开 Magic Frame（选框可见）
  - 输入提示词（非空）
  - 点击右侧面板 **图生图** 按钮
  - 在弹出的确认浮窗中查看：
    - 预览图是否为选框区域截图（“你看到哪里就截哪里”）
    - 提示词是否正确展示
  - 点击「取消」：不应触发生成
  - 再次触发，点击「确认生成」：应触发生成并在资源库出现 loading 占位
- **预期**
  - 取消不生成
  - 确认后才生成；资源库先出现 loading，占位完成后变为生成图
  - 生成图按原逻辑回填到画布（位于 Magic Frame 区域）

### 5) 文生图：输入浮窗与尺寸选择

- **步骤**
  - 点击右侧面板 **文生图** 按钮
  - 在浮窗中输入提示词
  - 选择任意比例（1:1、16:9、9:16、4:3、3:4）
  - 点击「生成资源」
- **预期**
  - prompt 为空时「生成资源」不可用
  - 点击「生成资源」后关闭浮窗，资源库插入 loading 占位
  - 生成完成后资源库出现生成图（不自动上画布）

## 常见问题与排查

- **图生图按钮不可点**
  - 确认 Magic Frame 已显示
  - 确认 prompt 非空
- **捏合缩放无效**
  - 确认在 iPad 真机或支持多点触控的模拟器环境下测试
  - 检查是否有手势冲突导致 pinch 被吞掉
