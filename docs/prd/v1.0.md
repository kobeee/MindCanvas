| 版本 | 日期 | 修改内容 |
| :--- | :--- | :--- |
| v1.0 | 2025-12-10 | 锁定 Nano Banana Pro 模型；增加社区功能；细化 iPad 侧边栏交互；明确登录鉴权方式 |

## 1. 全局导航架构 (App Navigation)

采用 iPadOS 标准的 **双栏/三栏布局 (Sidebar Style)**。

### 1.1 全局左侧主导航栏 (Global Sidebar)
*   **位置**：屏幕最左侧，常驻（可折叠）。
*   **菜单项 (Tabs)**：
    1.  **🖌️ 我的创作 (My Creations)**：核心工作区。
    2.  **🌊 MindStream (灵感流)**：即你提到的“MindFlow”，公共社区。
    3.  **💎 订阅 (Subscription)**：Pro 会员购买页。
    4.  **⚙️ 设置 (Settings)**：账号管理、API配置、退出登录。

## 2. 详细功能模块

### 2.1 登录/注册模块 (Auth)
*   **策略**：必须支持 Apple ID（审核要求）。
*   **支持方式**：
    1.  **Sign in with Apple** (优先级最高，按钮最大)。
    2.  **Google 登录**。
    3.  **GitHub 登录**。
    4.  **邮箱验证码登录** (输入邮箱 -> 发送 OTP -> 验证通过 -> 登录)。
*   **逻辑**：
    *   登录成功后，获取 `UserToken`，存储在本地 Keychain 中，随后跳转至主界面。

### 2.2 核心模块：画布编辑器 (The Editor)
这是点击“我的创作”列表项后进入的详情页。

#### A. 左侧资源栏 (Asset Library) - *你的核心需求*
不仅仅是历史记录，更是“素材库”。

*   **顶部功能区**：
    *   **[+] 按钮**：点击弹出 ActionSheet。
        *   选项 1：**从相册导入** (Import from Photos)。
        *   选项 2：**拍照** (Take Photo)。
    *   **逻辑**：导入/拍照后的图片，直接作为“原始素材”插入下方的列表中。

*   **列表区 (The List)**：
    *   **展示内容**：混合排列“用户导入的图”和“AI 生成的图”。
    *   **Loading 状态**：点击“生成”按钮瞬间，列表顶部插入一个占位卡片，显示 Loading 骨架屏/转圈动画。
    *   **选中态交互**：点击某张图片，图片边框高亮，并**浮出悬浮菜单 (Floating Menu)**，包含 4 个按钮：
        1.  **[+] Add to Canvas**：
            *   若画布无选区：自动在画布中心新建一个 Frame 并贴入该图。
            *   若画布有选区：将该图填入当前选区。
        2.  **[⬇️] Download**：保存到系统相册。
            *   *逻辑限制*：如果 `is_generated == false` (即用户自己导入的图)，此按钮**置灰/不可点**。
        3.  **[🌐] Publish**：发布到 MindStream。
            *   *逻辑限制*：同样仅针对 AI 生成/二创后的图片开放。点击后弹出简单的“添加标题”弹窗，确认后上传。
        4.  **[🗑️] Delete**：从列表中删除该资源。

#### B. 中间画布 (Infinite Canvas)
*   **技术**：WKWebView + tldraw (Web) + Bridge。
*   **核心能力**：
    *   支持手绘线条。
    *   支持图片图层 (从左侧拖入或点击添加)。
    *   **Frame 逻辑**：用户必须创建一个 Frame (画框)，AI 才会针对这个框的内容进行生成。

#### C. 右侧控制面板 (Control Panel)
*   **配置**：
    *   **API Key**：默认使用官方后端，但支持用户填入自己的 Key (如有必要)。
    *   **Model**：当前锁定为 **"Nano Banana Pro"** (Gemini 3 Pro Image)。
        *   *UI*：显示为 "Model: Nano Banana Pro (v1)"，暂时置灰不可选，为未来扩展留口子。
*   **生成触发**：
    *   **Prompt 输入框**。
    *   **Generate 按钮**：点击后 -> 发送请求给你的服务器 -> 左侧列表插入 Loading 卡片。

### 2.3 社区模块：MindStream (灵感流)
*   **布局**：瀑布流 (Masonry Layout)。
*   **内容**：展示其他用户通过“Publish”按钮发布的图片。
*   **卡片信息**：图片缩略图、作者头像、点赞数。
*   **点击详情**：
    *   大图预览。
    *   **Prompt (可选)**：如果作者允许，显示提示词。
    *   **"Remix" 按钮 (抄作业)**：点击后，自动创建一个新 Project，将这张图作为参考底图 (Image Input) 放入你的画布。

## 3. 技术架构 (Technical Architecture)

鉴于你有自己的服务器，且需要控制 Nano Banana Pro 的调用，架构调整如下：

### 3.1 客户端 (iPad App)
*   **UI 框架**：SwiftUI (负责 Sidebar, MindStream, Settings, 左侧资源栏, 右侧控制栏)。
*   **Canvas 容器**：WKWebView (加载本地 HTML/JS 运行 tldraw)。
*   **网络层**：Alamofire (请求你的后端)。

### 3.2 你的后端 (Your Server)
*   **语言建议**：Python (FastAPI) 或 Node.js (NestJS/Express)。
*   **核心接口**：
    1.  `POST /auth/login`：处理第三方登录验证，发放 JWT。
    2.  `POST /generate`：
        *   接收：Prompt, Base64 Image (画布截图/参考图), Parameters。
        *   动作：调用 Google Gemini API (Nano Banana Pro)。
        *   返回：生成的图片 URL (建议存 OSS/S3) 或 Base64。
    3.  `GET /feed`：获取 MindStream 的图片列表。
    4.  `POST /publish`：将图片标记为公开。

## 4. 开发注意事项 (Dev Checklist)

1.  **iPad 适配**：SwiftUI 的 `NavigationSplitView` 在 iPad 上表现极佳，但要注意**Split View 的显示模式**（`.balanced` 或 `.allVisible`），防止侧边栏默认被隐藏让用户找不到菜单。
2.  **WebView 通信**：
    *   **Swift -> JS**：`webView.evaluateJavaScript("add_image_to_canvas('url')")` (实现左侧点击加号图片上屏)。
    *   **JS -> Swift**：`window.webkit.messageHandlers.canvasUpdate.postMessage(...)` (当用户画完框，通知 Swift 准备好生成区域的数据)。
3.  **审核防坑**：
    *   **UGC 内容审核**：因为有 MindStream 社区，必须要有“举报 (Report)”和“拉黑 (Block)”功能，否则 App Store 会以“无法过滤有害内容”为由拒审。
    *   **访客模式**：Apple 建议允许用户在不登录的情况下体验部分功能（比如在画布画画，但不能生成，或生成需要看广告/登录）。如果一打开 App 就强制登录，容易流失用户，但如果是 B 端工具类，强制登录也可以接受。
